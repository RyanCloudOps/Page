# Cloud Quest — Portafolio de Gary Flores

Portafolio personal con temática arcade, bilingüe (ES/EN), hecho con HTML, CSS y JavaScript sin frameworks.

## Probar en local

```bash
python -m http.server 5500
```

Abre http://localhost:5500

## Archivos

- `index.html` — contenido (el texto en español está aquí)
- `script.js` — traducciones al inglés (`EN`), inventario de skills (`ITEMS`), puntuación, nubes, sonido y el código Konami
- `styles.css` — estilo arcade (los colores son variables en `:root`)
- `cv-gary-flores.pdf` — el CV que se descarga desde los botones
